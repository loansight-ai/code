# 데이터 관리

현재 데이터 출처와 수집 방법은 미정이며, 수집한 데이터는 없습니다.

## 데이터 등록 양식

| 항목 | 내용 |
|---|---|
| 데이터명 | 미정 |
| 제공 기관 및 원문 URL | 미정 |
| 수집 방법·수집일·대상 기간 | 미정 |
| 이용 조건 및 재배포 가능 여부 | 미확인 |
| 원본 보관 위치 | 미정 |
| 전처리 코드 및 처리 내용 | 미정 |
| 실행 시 필요한 경로·다운로드 방법 | 미정 |

## 컬럼 설명 양식

| 컬럼 | 의미 | 자료형 | 단위 | 결측값 처리 | 출처 |
|---|---|---|---|---|---|

## 재현성

원본과 전처리 결과를 구분하고, 필요하면 `raw_data/`, `cleaned_data/`를 추가합니다.
외부 데이터가 필요하면 다운로드 절차와 저장 경로를 기록합니다.
