# 재무지표 상대 구간: 개발 적용 규칙

기준일: 2026-11-01. 적용 범위는 2016~2025년, 4개 업종, 전체기업 기준, 핵심 재무지표 5개다. 이 문서는 화면 구현을 위한 전달 자료다.

## 1. 파일과 조회 키

같은 폴더의 `2016-2025_화면비교기준.csv`를 사용한다. UTF-8 BOM 형식이며, 한 행은 연도·산업코드·지표 조합이다. 회사의 결산 연도와 업종, 지표에 해당하는 행을 선택한다. 기업대상 `전체`는 ECOS의 기업 규모 구분이며, OFS 표본이 국내 전체 기업이라는 의미는 아니다.

- `비교산업`: 사분위수의 실제 산업 범위. ECOS의 부동산업과 OFS의 부동산임대업은 서로 다르므로 회사 업종에 맞는지 확인한다. 부동산업 값을 임대업 전용 기준으로 표시하지 않는다.
- `업종합산_산업`, `업종합산비율`: 별도 참고값의 산업 범위와 값. 사분위수와 출처·범위가 다를 수 있다. 총자산영업이익률 업종합산값은 ECOS 지표를 이용한 기존 근사값이다. 구간 계산에 합산비율을 사용하지 않는다.
- `Q1`, `중앙값`, `Q3`: 구간 경계. 각 값 옆의 `*_ECOS여부`는 해당 값이 ECOS에서 추출된 값이면 `1`, OFS 표본에서 계산한 값이면 `0`, 값이 없으면 빈칸이다. 빈칸은 0이 아니다.
- `표본수`: OFS에서 유효하게 계산한 기업 수. ECOS 행에는 제공되지 않아 빈칸이다.
- `*_CI95_하한`, `*_CI95_상한`: 해당 OFS 표본 경계의 95% 부트스트랩 신뢰구간. ECOS에는 OFS 신뢰구간을 적용하지 않는다.
- `재추출_4구간_평균변경률`: OFS 표본 재추출 시 기존 표본 기업의 구간이 바뀐 평균 비율. 0.133은 13.3%다. 특정 기업이 이동할 확률이 아니다.
- `상태`: `사용가능`은 세 경계가 모두 있음, `부분결측`은 일부만 있음, `보류`는 세 값 모두 없음이다. 빈칸은 null로 읽는다.

CSV의 지표 단위는 모두 `%`다. 이자보상비율을 화면에 `배`로 표시하려면 회사값, Q1·중앙값·Q3, 신뢰구간과 업종합산비율을 모두 100으로 나눈다. 비교는 변환 전 값끼리 또는 변환 후 값끼리 일관되게 수행한다. 예: 160% = 1.6배.

## 2. 비교 전 확인

1. 회사 지표와 기준값의 연도·산업 범위·단위 및 산식을 맞춘다. 부동산업과 부동산임대업은 자동으로 같은 업종으로 취급하지 않는다.
2. 회사값이 없거나 분모가 0 이하인 등 산식 적용이 불가능하면 구간 대신 `비교할 수 없음`을 표시한다. 부채비율은 자본총계가 0 이하이면 사분위수 비교를 생략하고 `자본잠식 여부 확인 필요`로 표시한다. 자본총계가 누락되면 자본 상태를 단정하지 않는다.
3. 세 경계 중 하나라도 없으면 네 구간을 완전하게 나눌 수 없으므로 `비교 기준 확인 중`을 표시한다. 존재하는 값은 상세 참고값으로만 표시할 수 있으며 다른 출처의 값이나 업종합산비율로 결측을 채우지 않는다.
4. 세 경계가 존재하고 `Q1 ≤ 중앙값 ≤ Q3`인지 확인한다. 순서가 유효하지 않으면 비교를 보류한다. 비교 전 반올림하지 않는다.

부동산임대업 총자산영업이익률은 손익기간 미확인으로 보류되어 있다. 데이터에 값이 없다는 뜻으로 해석하지 않는다. 부분결측 행도 결측 경계가 생기기 전까지 전체 구간 판정은 보류한다.

## 3. 상대 구간 계산

회사 지표값을 `x`라 할 때 오름차순 네 구간으로 나눈다. 경계가 같은 경우에도 아래 조건을 위에서부터 순서대로 적용한다.

| 조건 | 표시 문구 |
|---|---|
| `x < Q1` | 하위 25% 구간 |
| `Q1 ≤ x < 중앙값` | 25~50% 구간 |
| `중앙값 ≤ x ≤ Q3` | 50~75% 구간 |
| `x > Q3` | 상위 25% 구간 |

동점과 보간 때문에 각 구간에 정확히 25%가 들어간다는 뜻은 아니다. 이 구간은 값의 크기에 따른 위치이며, 특히 부채비율은 값이 높다고 재무 상태가 좋다는 뜻이 아니다. 구간명만으로 위험·안전 등급을 부여하지 않는다.

## 4. 경계 부근 안내

OFS 표본 경계에 대해서만, 회사값 `x`가 Q1·중앙값·Q3 중 하나 이상의 **유효한 95% 신뢰구간에 포함**되면 안내한다. 양 끝점도 포함한다. 계산은 화면 반올림 전 값으로 한다.

```text
경계부근 = any(
  해당 경계_ECOS여부 == 0
  and CI_하한과 CI_상한이 모두 존재
  and CI_하한 <= x <= CI_상한
  for 경계 in [Q1, 중앙값, Q3]
)
```

참이면 `경계 부근: 표본 구성에 따라 상대 구간이 달라질 수 있습니다.`를 표시하고, 거짓이면 이 안내를 숨긴다. 여러 CI에 포함되어도 안내는 한 번만 표시한다. OFS 경계의 CI가 누락·역전된 경우에는 경계 부근 여부를 알 수 없으므로 위 문구를 띄우지 않되, 내부 상태를 `확인 불가`로 기록한다. CI 밖이라고 구간이 절대 바뀌지 않는다는 뜻은 아니다. ECOS 기준에는 OFS CI를 붙이지 않는다.

## 5. 화면 구성과 문구

**기본 카드**: 지표명, 회사값, 상대 구간, 기준 연도·비교산업을 표시한다. OFS 기준이면 `OFS 수집 표본 n개 기업`을 추가한다. ECOS의 표본 수는 추정하지 않는다. 4절 조건을 만족할 때만 경계 부근 안내를 표시한다.

**상세 화면**: Q1·중앙값·Q3과 회사 위치를 표시하고, OFS 기준에는 표본 수와 각 경계의 95% CI를 함께 표시한다. 민감도는 `표본을 다시 뽑아 경계를 계산했을 때 기존 표본 기업의 구간이 평균 ○○% 변경되었습니다. 내 기업의 구간이 바뀔 확률은 아닙니다.`로 설명한다. OFS 표본 분포 그래프가 필요한 경우 기존 연도별 EDA 결과를 별도 참조한다. 이 CSV는 그래프를 다시 그릴 기업별 원자료를 포함하지 않는다.

업종합산비율을 함께 보여줄 때는 `업종합산비율 (참고)`으로 구분하고 산업 범위를 명시한다. 업종합산비율은 사분위수나 기업별 중앙값이 아니다. 표본이 적어도 임의의 통과·실패 임계값을 적용하지 않고 실제 표본 수와 CI를 보여준다. 표본이 업종 전체를 대표한다는 보장은 없다.

## 6. 구현 확인 예시

- `Q1=100, 중앙값=150, Q3=200`, `x=100`: `25~50% 구간`. `x=150` 또는 `x=200`: `50~75% 구간`. `x=200.01`: `상위 25% 구간`.
- OFS Q1 CI가 `90~110`이고 `x=110`이면 경계 부근 문구 표시. 세 CI 모두 밖이면 숨김.
- ECOS Q1=10, 중앙값=20, Q3 결측이면 `비교 기준 확인 중`. Q3를 다른 표본값으로 대체하지 않음.
- 이자보상비율 회사값 160%와 기준 200%는 화면에서 각각 1.6배와 2.0배다.
- 부채비율의 자본총계가 0 이하이면 음수 비율로 구간을 매기지 않고 자본잠식 확인을 안내한다.
