## 원천과 생성

- 백업: `loansight_ofs_20261031.dump` (3,044,186,621바이트, PostgreSQL 16.15).
- 백업 헤더 생성 시각: 2026-10-31 16:47:23. 시간대는 확인하지 않았다.
- CSV 내보낸 날: 2026-11-01. 실제 조회 범위·수집 시각 기준일은 2026-10-26으로 유지한다.
- 전체 DB를 복원하지 않고 pg_restore로 필요한 TABLE DATA만 COPY 스트림으로 읽었다.
- 재무는 `public.mv_fs4_wide_ok`의 피벗·상태 필터를 재현했다. 금액은 부동소수점으로
  변환하지 않았으며 코드의 앞자리 0, 빈값, 문자열 값, 사건 본문의 줄바꿈을 보존했다.
- `service` 스키마의 CFS/OFS 혼합 복사 테이블은 사용하지 않았다.
- 재무는 2,090개사·2015~2026년, 전부 OFS다. 2026년 35행도 원본대로 포함한다.
- 파일별 SHA-256·크기·원천·품질 경고는 [manifest](manifest_20261101.json)에 기록한다.

## 이전 묶음과 달라진 점

기존 18,417행 중 CFS였던 14,576개 회사·연도가 OFS로 바뀐다. 기존 OFS 3,818개
회사·연도는 유지되지만 일부 값은 덤프의 보충·보류 상태가 반영돼 다를 수 있다.
나머지 23개 회사·연도는 새 public.fs4_report에 없으며 CFS로 대신 채우지 않는다.
재무 없는 조회 대상 기업은 기존 180개사에서 181개사가 된다.

사건·조회 범위의 키와 행 수는 같다. 조회 범위 값은 이전과 같고, 사건의 title 4행·detail
782행은 덤프 값과 다르므로 이전 CSV를 복사하지 않고 덤프의 값을 사용했다. 실제 사건 검수
상태가 갱신됐다는 뜻은 아니다.

## 품질과 미정 사항

- 재무값은 덤프의 기존 상태 필터를 보존한 자료다. 공시 원문에 대한 독립 검수 완료로
  간주하지 않는다. `주석0` 65,464행 중 64,956행은 원래 `해당없음(규칙)`에서 왔다.
  `잔여(확인필요)`도 원래 ok 필터에 포함된다. 추후 주석 검증의 대상으로 남긴다.
- 덤프의 주석 본문·표·보충 이력을 이번 CSV 적재로 서비스 주석 테이블에 연결하지는 않는다.
- 이자비용 0의 보류, 차입 계정 범위, 미정 산식 등 기존 분석 계약을 변경하지 않는다.
- 코스나인 2024·2025의 접수번호 `20260324000091` 중복은 원본대로 경고한다.
- 재무 없는 사건 기업 92개사, 검증 미완료 사건 2,698건, 감사의견 확인 불완전 386개사다.
- 안내문에 있던 `fs4_report_flag`는 덤프에 없었다. 예외 목록이나 핵심 지표
  `common/indicators_ofs/indicators_wide.csv`를 임의로 생성하지 않았다.
- 전체 아카이브 무결성 검사와 실제 DB 전체 복원은 수행하지 않았다.
