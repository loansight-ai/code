# OpenDART 기업코드·KSIC11 동기화 메모

기준일: **2026-10-28**

이 디렉터리는 Git과 Docker 이미지에 포함되는 초기 수입 자료입니다. 파일 역할과 초기 실행·운영 데이터 보관 방법은 [백엔드 기업 검색 안내](../../README.md#기업-검색)를 따릅니다.

`companies_opendart_ksic11.csv`는 기업 식별과 KSIC 매칭이 완료된 **117,097개 기업, 18열**의 스냅샷입니다. 전체 DART 기업 목록은 아닙니다. UTF-8 BOM이며 코드는 문자열로 읽습니다.

## 필드 기준

- 기본키: **`corp_code` 8자리**. 회사명·법인번호·사업자번호로 행을 합치지 않습니다.
- OpenDART 기업개황 필드 16개에 `corp_code`, **`ksic11_code`**를 포함합니다.
- `corp_cls`: Y 유가 / K 코스닥 / N 코넥스 / E 기타. `est_dt`: YYYYMMDD, `acc_mt`: MM.
- `induty_code`는 실제 API 원본을 확인한 **668건만** 기입했습니다. 나머지 공란은 미확보 값입니다.
- `ksic11_code`는 별도로 연결한 **KSIC 제11차** 코드입니다. `induty_code`와 서로 복사하지 않습니다.
- KSIC 코드는 대분류 영문 1자리 또는 숫자 2~5자리입니다. 하위 분류를 추정하거나 5자리로 맞추지 않습니다.

## 갱신 순서

1. 최신 **CORPCODE.zip**을 읽고 `corp_code`로 기존 CSV와 비교합니다. CSV에 없는 코드는 신규뿐 아니라 이전 전처리·미매칭 제외 기업일 수 있습니다.
2. 신규 코드와 기업정보 변경 대상을 OpenDART `company.json`으로 조회해 `corp_code` 기준으로 갱신합니다. ZIP의 `modify_date`, 조회일, 원본 해시는 CSV 밖의 동기화 상태 파일에 보관합니다.
3. 업종은 최신 기업개황의 **업종명**을 KSIC11 공식 코드표와 검증된 명칭 매핑에 대조합니다. 기존 파일의 매핑값을 단순히 신규 기업에 복사하거나, API `induty_code`가 KSIC11이라고 가정하지 않습니다.
4. 같은 업종명이 여러 분류 단계에 반복되면 확인 가능한 상위 코드를 적용합니다. 업종 공란·후보 중복·등록번호 충돌은 별도 검토 파일에 둡니다.
5. 내보내기 전 `corp_code` 중복 0개, 코드 유효성·앞자리 0 보존, 신규·변경·미매칭 건수를 확인합니다. 새 스냅샷을 저장하고 이전 버전도 보관합니다.

## 유의사항

- 이름으로 기업개황을 연결해야 한다면 **원문 일치부터** 확인합니다. 영문명의 대소문자·문장부호를 먼저 지우면 다른 후보가 합쳐질 수 있습니다.
- 동명 후보를 등록번호로 구분할 때는 **해당 후보 전체를 조회한 뒤** 판단합니다. 일부 후보만 조회해 유일하다고 확정하지 않습니다.
- 같은 법인·사업자번호라도 다른 `corp_code`가 있을 수 있으므로 자동 병합하지 않습니다.
- 조회 실패나 미확보 공란으로 기존 정상 값을 덮어쓰지 않습니다. 최신 ZIP에서 빠진 코드도 먼저 별도 상태로 분리해 확인합니다.
- 이 CSV는 로컬 기업개황을 OpenDART 형식으로 변환한 자료입니다. 전 기업을 API로 새로 조회한 결과는 아닙니다.

공식 가이드: [고유번호](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018), [기업개황](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002).
