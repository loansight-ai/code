## 사용 시 주의

- 이자보상비율(629)은 원천 단위가 %다. 서비스가 '배'를 쓰면 100으로 나눈다
- 잔액 기준: 회전율(807·809·810)은 분모가 기초·기말 평균 잔액, 700번대(702·707·701·710)는 기말 잔액 정태비율, 611·612·629·506은 손익 항목끼리라 잔액 기준이 없다
- 회전율 3종의 분자는 모두 매출액이다(매출원가·매입액 아님)
- 원천은 법인세 신고 별도재무제표를 업종 합계로 계산한 비율이다. 개별 회사 비율의 중앙값과 다르고, 연결재무제표 값과 직접 비교할 수 없다
- 부동산 임대업은 원천에 681(부동산 임대 및 공급업)이 없어 L68 부동산업(개발·공급·관리·중개 포함)으로 상위 업종 대응했다
- 매출액증가율은 합병·분할·업종 변경을 반영한 값이라 전년도 공표 금액으로 계산한 성장률과 다를 수 있다(통계편 i쪽)

## 검증

- 행 수: 업종×규모 179개 조합 중 173개는 42행(지표 14개 × 3개년), 원천 미수록 C12의 6개 규모 조합은 각각 33행
- 판독 실패: 173개 표 × 지표 11개 중 0건
- 내부 정합성: 부채비율 = (100 − 자기자본비율) ÷ 자기자본비율 × 100 관계를 518쌍에서 확인, 어긋난 곳 0건
- 재대조: 무작위 10개 값을 다른 추출 방식(pdftotext -raw)으로 다시 읽어 10개 모두 일치. 건설업 전체 쪽(인쇄 444)은 이미지로 육안 대조
- ECOS 전수 대조(2026-10-30): '확보' 값 5,709개 전부를 ECOS Open API StatisticSearch(통계표 501Y005~501Y008, ecos_mapping.csv 코드 사용)로 받아 비교. 업종×규모×지표 1,903개 조합, 일치 5,709 / 불일치 0 / ECOS 응답 없음 0

## 산식 출처 (v2에서 채움)

- 유동비율·부채비율·자기자본비율은 ECOS 통계설명(통계개념정의)의 산식과도 일치

## ECOS Open API

- 같은 값을 ECOS에서 받을 수 있다: StatisticSearch / 통계표 501Y005·501Y006·501Y007·501Y008 / 주기 A / 항목 순서 업종 → 규모 → 계정항목
  - 예: `https://ecos.bok.or.kr/api/StatisticSearch/{인증키}/json/kr/1/10/501Y007/A/2023/2025/F/A/707` → 건설업 종합 부채비율
- ECOS 계정항목 코드는 책자와 4개가 다르다: 이자보상비율 627, 재고자산회전율 806, 매출채권회전율 808, 매입채무회전율 809. 책자 코드를 그대로 넣으면 ECOS 629(사내유보율)·807(상(제)품회전율)·809(매입채무회전율)가 나오므로 반드시 ecos_mapping.csv로 바꿔 호출한다
- 대분류 업종 코드도 다르다(C10-34→C, F41-42→F, G45-47→G, L68→L)
- ECOS 값과 이 CSV 값은 전부 일치한다(아래 '검증'). 다음 연도부터는 PDF 대신 ECOS API로 받아도 같은 값이다
- source_release.csv의 공표일·출처 URL·이용조건은 PDF에 적혀 있지 않다. file_path·file_sha256·retrieved_at은 원본을 보관하는 쪽에서 채운다
