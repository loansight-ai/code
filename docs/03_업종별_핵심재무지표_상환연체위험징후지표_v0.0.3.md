# 업종별 핵심 재무지표와 부실징후

## 1. 업종별로 보는 핵심 재무지표·재무비율

먼저 볼 지표는 업종마다 "돈이 어느 단계에서 묶이는가"에 따라 달라진다.

## 4. 상환·연체 위험징후 단계 기준 (경고·주의·관찰)

징후 단계는 담당자가 무엇부터 확인할지 정하는 순서이며, 은행의 자산건전성 분류·내부 등급·여신 결정을 대신하지 않는다. 경고와 관찰은 각각 하나의 기준으로 두고, 세부 유형(개별·복합, 정량 참고, 투자·처분)은 주의 단계에만 둔다.

### 4-1. 단계 정의

| 단계 | 항목 | 해당하는 기준 | 화면 처리 |
| --- | --- | --- | --- |
| 경고 | 감사의견 비적정·계속기업 관련 중요한 불확실성 | 사건 (감사인 판단) | 패널 최상단 고정, 원문 확인 필수 항목으로 지정 |
| 경고 | 완전자본잠식 (자기자본 ≤ 0) | 사건 (재무상태표에 확정된 사실) | 패널 최상단 고정, 원문 확인 필수 항목으로 지정 |
| 경고 | 어음·수표 지급거절, 회생절차 개시신청 공시 | 사건 (금융기관·법원) | 패널 최상단 고정, 원문 확인 필수 항목으로 지정 |
| 경고 | 기한이익상실 사유 발생 문장 | 사건 (채권자가 상환을 요구할 수 있는 상태) | 패널 최상단 고정, 원문 확인 필수 항목으로 지정 |
| 경고 | 이자보상비율 1배 미만 직전 3년 연속 모두 | 지속: 주의 항목이 3년 계속됨 | 패널 최상단 고정, 원문 확인 필수 항목으로 지정 |
| 주의 | 부분자본잠식 (자기자본 < 납입자본금) | 절대 경계: 납입자본금 | 확인 항목 목록에 추가, 근거 원문 연결 |
| 주의 | 당기 이자보상비율 1배 미만 | 절대 경계: 1배 | 확인 항목 목록에 추가, 근거 원문 연결 |
| 주의 | 흑자인데 영업CF 2년 연속 음수 | 절대 경계: 0 | 확인 항목 목록에 추가, 근거 원문 연결 |
| 주의 | 1년 내 만기 차입금 > 현금성자산 + 영업CF | 절대 경계: 상환재원 | 확인 항목 목록에 추가, 근거 원문 연결 |
| 관찰 | 업종 중앙값 대비 열위 | 상대 기준 | 추세 차트와 업종 내 위치만 표시 |
| 관찰 | 전기 대비 악화 추세 (업종별 핵심 지표) | 상대 기준 | 추세 차트와 업종 내 위치만 표시 |

### 4-2. 기준선을 세우는 원칙

업종마다 보는 지표와 정상 범위가 다르므로, 하나의 숫자로 모든 업종을 자르지 않는다. 기준의 성격(사건·수준·변화·조합)에 따라 기준선을 세우는 방법을 나눈다.

| 기준 종류 | 적용 | 기준선을 세우는 방법 | 이유 |
| --- | --- | --- | --- |
| 사건 기준 | 경고 | 공시상 사실의 유무로 판단하고 숫자 기준을 두지 않는다. | 업종과 관계없이 상환능력 훼손이 드러난 사실이다. |
| 절대 하한 | 주의(개별) 공통 | 의미가 정해진 경계값을 쓴다: 이자보상비율 1배, 자본잠식, 영업CF 0. | 1배 미만이면 영업이익으로 이자를 못 내는 등 업종과 무관하게 의미가 같다. |
| 업종 상대 기준 | 주의(개별) 업종 지표, 관찰 | 같은 업종·같은 연도 상장사 분포에서 나쁜 쪽 하위 25%이면 주의, 중앙값보다 나쁘면 관찰로 둔다. 비교 기업이 최소 수에 못 미치면 상위 분류로 올리고, 그래도 부족하면 '비교 보류'로 표시한다. | 소매 유동비율, 건설 부채비율처럼 업종마다 정상 범위가 달라 고정 숫자는 왜곡된다. |
| 변화 기준 | 주의(개별) 부실징후 | 전기 대비 변화폭이 업종 변화폭 분포의 나쁜 쪽 하위 25%이거나, 같은 방향의 악화가 2년 연속이면 주의로 둔다. | 부실징후는 수준보다 '매출보다 빠르게 증가', '급감'처럼 방향과 속도가 핵심이다. |
| 조합 기준 | 주의(복합) | 서로 다른 판단 영역(상환재원·유동성·재무구조 등) 2개 이상의 동시 악화만 인정하고, 같은 원인에서 나온 지표는 하나로 센다. | 단일 지표보다 동시 악화가 상환능력 저하를 더 설득력 있게 설명한다. |
| 고정 참고 수치 | 주의(정량 참고) | 보완안 수치를 그대로 쓰되 '업종 조정 전 참고'로만 표시한다. 업종 분포를 확보하면 업종 상대 기준으로 바꾼다. | 업종 구분 없는 일반 기준이기 때문이다. |

- 기준값마다 출처를 '팀 가설 / 공식 통계 / 현직자 확인' 중 하나로 표시한다. 한국은행 기업경영분석 업종 평균은 모집단·연도가 달라 비교 참고로만 함께 보여준다.

- 하위 25%, 2년 연속, 비교 기업 최소 수 같은 값은 팀 가설 제안이며, 업종 분포를 계산한 뒤 조정한다.
