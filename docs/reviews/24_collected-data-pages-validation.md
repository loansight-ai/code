# 수집 데이터의 기존 화면·재무 분석 연결 검증

검증일: 2026-10-30. 최초 적재는 [CSV 적재 검증](23_company-exported-data-validation.md),
API·버전·입력 선택 계약은 [백엔드 안내](../../backend/README.md#collected-company-data)에서
관리한다.

## 연결한 화면

| 화면 | 사용한 수집 데이터 |
| --- | --- |
| 기업 선택 | 기존 핵심 재무 분석 버튼으로 동일한 보고서·회계 범위의 저장 재무를 자동 사용 |
| 재무 요약 | 수집 버전을 지정해 기존 계산기로 산출한 계정·핵심 비율·증감·산식 입력 근거 |
| 실적 변동·현금흐름 | 같은 분석 스냅샷의 현금흐름·계정 증감·변동 분해와 수집 이력 |
| 사건 예측 메뉴 | 기존 사건 카드 안에서 회사 공시 사건 후보·원문 링크·조회 범위 제공. 모델 예측 결과는 계속 미제공 |
| 주석 작업의 분석 메뉴 | 기존 핵심 재무 분석 시작과 사건 화면 사용. 주석 검수 완료나 모델 예측으로 승격하지 않음 |

기업 선택의 기존 **핵심 재무 분석**은 기업·보고서·사업연도·회계 범위가 일치하는
저장 데이터가 있으면 자동으로 사용한다. 서버가 적재 UUID를 작업 조건에 고정하며
브라우저는 별도 원천을 선택하지 않는다. 수집 데이터 전용 패널·별도 버튼·상단 배너는
없다. 출처는 기존 분석 추가 정보에서 확인한다. 재수집·주석 보완은 OpenDART 경로를
사용하며, 일치하는 저장 재무가 없는 요청도 기존 수집 경로로 처리한다. 리스 옵션
변경은 같은 분석 원천 버전을 사용한다.

회사 전체 사건 후보는 선택한 결산 당시 알려진 사실과 구분한다. 후보 발췌는 React
텍스트로 표시하고 HTML로 실행하지 않는다. 후보가 없어도 회사가 정상이라고 표시하지
않으며, 감사의견 원문 확인 누락을 별도로 표시한다. 업종 통계 산출이나 모델 추론을
이번 변경으로 새로 제공하지 않는다.

## 자동 검사

- 신규 화면 검사 4건: 기존 버튼만 제공하고 원천 선택 없이 요청, 기존 재무 카드에
  분석값·기존 정보창에 출처 표시, 기존 사건 카드의 후보/조회 누락 표시,
  응답 범위 불일치 거부. 별도 데이터 패널·버튼·배너가 없는 것을 검사한다.
- 전체 프론트엔드: 17개 파일·116개 검사 통과.
- 최종 자동 선택 동작: CSV 계정 어댑터·공개 조회 API·인증된 분석 실행·기존 재무 흐름을
  PostgreSQL 테스트 DB에서 실행해 12 passed. 기본 요청의 자동 원천 선택, 재수집의
  OpenDART 유지, OFS 미보유 시 CFS 대체 금지를 확인했다. 적재 검사는
  [최초 적재 검증](23_company-exported-data-validation.md)의 9건과 구분한다.
- API 키 미설정 상태에서 CSV 분석이 성공하고 OpenDART 다운로드 함수를 호출하지 않는
  것을 검사했다. OFS 미보유와 CSV/주석 보완 동시 요청은 422로 거부됐다.
- 프론트 TypeScript·Vite 빌드, ESLint 및 변경 백엔드 파일 Ruff 검사 통과.

## 실제 로컬 서비스 확인

최신 백엔드 이미지를 빌드하고 Compose API·Worker·Relay를 갱신했다. 세 서비스 모두
healthy 상태이며, 기존 DB·아티팩트 볼륨을 유지했다. 프론트 개발 서버는 HTTP 200이다.

기업 `00164478`·접수번호 `20260318001395`·2025년·CFS로 실제 HTTP 조회:

- 재무 1행, 원보고서 추세 5행, 원천 기준일 2026-10-26.
- 매출 `31,062,912,000,000`원. OFS는 재무 0행, 보유 범위 CFS만 반환.
- 로컬 검증용 새 사용자 세션에서 원천 선택 필드 없이 기존 재무 분석을 요청하고
  저장된 CSV가 자동 선택된 뒤 실제 Relay→RabbitMQ→Worker
  완료까지 확인했다. 사용자 코드/세션 쿠키는 출력하거나 문서에 기록하지 않았다.
- 최종 자동 선택 분석 ID `b7c57a13-7ade-460b-b5e0-3f382c0ffe73`, 상태 `SUCCEEDED`.
- 입력 적재 ID `6fecb15e-cee8-4712-8a15-5a62669740a0` 고정, 매출값 일치,
  기존 계산기의 유동비율 `147.9360`%, 지표 34개 반환.
- 인증된 원천 JSON 다운로드에서 같은 적재 UUID를 확인했다.

브라우저 제어 호스트가 사용 불가여서 실제 브라우저에서 시각 검수는 수행하지 못했다.
화면 동작은 React DOM 검사로, 실제 서비스 연결은 HTTP와 DB/Worker 검증으로 확인했다.
기존 원문 HTML/XML을 새로 확보하거나 업로드하지 않았다. 변경은 주제별 로컬 커밋으로
분리하며 원격 푸시·외부 서비스 배포는 수행하지 않았다.
