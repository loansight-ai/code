# 재무 자료 상태 표시 검증

> 2026-10-29 · 화면설계서의 자료 상태 규칙 반영

표시 계약과 미정 정책은 [프론트 재무 안내](../../frontend/README.md#financial-summary)에서 관리한다. 기존 재무/주석 차입금 변경을 유지하며 공통 자료 상태 컴포넌트를 추가했다. 백엔드 금액·기존 결과 스냅샷과 DB 스키마는 이번 표시 작업에서 변경하지 않았다.

재무 요약 테스트 11개에서 실데이터 조회·기존 주석 소계·옵션 변경 외에 다음을 확인했다.

- 입력 누락은 미확보·자료 없음, 분모 0/음수는 계산 불가로 카드와 산식 창에서 일치한다.
- 근사 데이터는 주황 배지와 값 옆 사유를 표시하며 사유 없는 근사 응답은 거부한다. 근사 분기는 테스트 응답으로 검증했다.
- 실제 0은 0으로 유지하고 사채 미확보는 회색 자료 없음으로 표시한다.
- 입력 누락 지표의 참고·확보 개수·주석 보강 안내를 표시한다.
- 부호 전환은 증가율 대신 계산 불가·전환 상태·증감 금액으로 표시한다.

프론트 전체 13파일·83개 테스트, TypeScript·ESLint·프로덕션 빌드를 통과했다. 실제 오뚜기 OFS/CFS에서 차입 소계·검산 근거·리스 변경과 태블릿 가로 넘침 없음을 확인했고 브라우저 페이지 오류는 0이었다. `.run/financial-validation/note-borrowing-OFS.png` 캡처에서 확정 배지와 사채·임대보증금의 미확보 배지/자료 없음을 확인했다. Vite의 기존 큰 청크 경고는 남아 있다.
