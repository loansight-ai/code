# 저장된 주석 결과 화면 검증

검증일: 2026-10-28. 수집 완료 패널과 내 분석 작업 상세의 **주석 결과 보기**를 `/notes/:structureId`로 연결했다. API·원문 처리 계약은 [주석 조회 API](../../backend/README.md#note-import-api), 후속 범위는 [개발 계획](../design/06_delivery-and-validation.md#roadmap)에서 관리한다.

## 확인한 동작

- 저장된 목차·구간·표의 조회, 저장된 부모 관계에 따른 목차 필터, 본문 부분 검색, 표 필터와 30개씩 추가 조회.
- 구간 선택 시 저장된 XPath에 대응하는 열람본 앵커 강조. URL 필터·구간 선택의 새로고침 복원.
- 현재 Workspace 권한 확인, 다른 사용자 결과 404, 미완료 원문 409, 원문 해시 변조 시 503. 브라우저가 접속 전 원문을 요청하지 않는지 확인.
- DOMPurify 허용 목록으로 이벤트 속성·스크립트·이미지·외부 링크·스타일·폼·SVG 제거, 표 병합 속성과 앵커 보존. iframe의 스크립트 권한 제외 및 CSP 확인.
- 뉴트리(`01214248`), 사업보고서 2025.12, 접수번호 `20260320001416`의 실제 수집·구조화 결과를 Chrome에서 확인. PC 1440×1000은 별도(OFS) 784개 구간, 태블릿 820×1180은 연결(CFS) 867개 구간. 표 선택·원문 강조·새로고침 복원·부모 화면 가로 넘침 없음을 확인하고 화면을 검토했다.

## 검사

- 백엔드 Ruff 통과. 전체 pytest 96개 통과·5개 건너뜀. 원문 변조 거부 검사를 추가한 뒤 관련 통합 테스트 5개 재통과.
- 프론트 Vitest 62개 통과, TypeScript·Vite 빌드 통과. 기존 번들 크기 안내는 남아 있다.
- 실제 기업 검색 E2E PC·태블릿 2개 통과. 실제 수집·결과 열람 E2E PC·태블릿 2개 통과. 초기 표 체크 표시 갱신 문제를 수정한 뒤 수집·결과 열람 검사를 다시 실행했다.

## 검증 한계

목차의 미확정 관계는 구조 확인 필요로 표시하며 결과 전체를 내용 검수 전으로 표시한다. 원본 바이트 보존과 화면 표시 검사는 회계 사실·계층 정확도·표 기간 대응의 검수 완료를 뜻하지 않는다. 열람용 서식은 원본과 다를 수 있다. 원문 HTML은 전체를 한 번에 조회하며, 교차참조 이동·열람 기록·담당자 검수 저장·재무 분석은 이번 범위에 포함하지 않는다.
