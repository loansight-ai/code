## 확인

- 저장소 Markdown의 로컬 경로·명시적/제목 앵커를 전수 검사했다. Git 제외 `.run/`,
  의존성 폴더와 외부 URL 접근 가능성은 전수 확인 대상에 포함하지 않았다.
  검사 대상은 60개 문서·387개 로컬 참조이며 누락 경로/앵커는 0개다.
- 실행 중인 로컬 OpenAPI의 근거 묶음·`exposure-summary`·사실 검수·`signals`와 재무
  조회 경로/메서드를 확인했다. 실제 프론트 라우터·원문/패널 이동·상대 구간/만기 계산·
  사실 비교 키·빈 규칙 registry를 담당 계약과 대조했다.
- 기존 Markdown의 명시적 HTML 앵커 보존과 `git diff --check`를 확인했다.
  애플리케이션 코드·DB·원본 CSV·dump를 수정하지 않았으므로 앱 테스트·빌드는 이번
  문서 작업에서 재실행하지 않았다. 기존 검사 결과는 31~35번 검증 기록의 당시 범위다.

상대 구간의 최소 표본 임계값·운영 위험단계·승인 정책을 새로 정하지 않았다. 실제 Codex
호출은 사용자 선택에 따라 보류 상태를 유지하며, 모델 학습·추론·인증정보 복사와 외부 배포는
수행하지 않았다. 총자산영업이익률의 산식/기간 불일치, CSV 누락값 자동 보완·검토 메모
서버 저장·운영 규칙 등록·예측 시점/모델 특징 계약의 미완료 상태는 유지했다.
