# DART 기업 검색 검증

2026-10-28 · [Issue #17](https://github.com/loansight-ai/code/issues/17)

기업 검색을 가상 목록에서 OpenDART 기업고유번호 원장 기반 검색으로 연결했다. 사용법·원천·보관 경로·갱신·응답 계약은 [백엔드 안내](../../backend/README.md#기업-검색), 화면과 예시 모드 구분은 [프론트 안내](../../frontend/README.md)에서 관리한다.

## 실제 원천 확인

- 설정된 인증키로 공식 `corpCode.xml` ZIP을 내려받아 기업 119,798건을 검증하고 Native 캐시에 저장했다. 인증키와 원본 ZIP은 Git에 포함하지 않았다.
- `005930` 검색에서 삼성전자(`00126380`)를 선택하고 고유번호·영문명·종목코드·목록 변경일 표시를 확인했다. 부분 검색이므로 다른 기업의 고유번호에 검색 문자열이 포함되면 함께 반환되며 정확히 일치하는 코드가 우선한다.
- 실제 원장에는 `0068Y0` 등 영문자가 포함된 종목코드가 있어 숫자만 허용하는 검증을 사용하지 않았다. 업종·시장·결산월은 원장에 없으므로 미조회 상태를 유지했다.

## 검증 결과

| 방법 | 기대 결과 | 실제 결과 |
|---|---|---|
| 백엔드 단위 테스트 전체 (`tests/integration` 제외) | 기업 원장 파싱·검색·캐시·입력 검증과 기존 기능 유지 | 38개 통과 |
| 프론트 Vitest 전체 | 실제 검색 선택·실패/빈 결과 구분·재시도·한글 입력, 기존 예시 흐름 유지 | 46개 통과 |
| `pnpm build`, `pnpm lint`, Ruff | 타입·번들·정적 검사 성공 | 통과. 번들 크기 500kB 경고는 남음 |
| Chrome desktop/tablet, 실제 기업 검색 및 기존 입력 E2E | 실제 기업 선택·영문 종목코드·검색 결과 없음, IME·커서·URL 복원 동작 | 8개 통과 |

실제 검색 E2E는 `LOANSIGHT_LIVE_COMPANY_TEST=1`일 때 실행하며 DART API 또는 준비된 캐시가 필요하다. 실행 예: `LOANSIGHT_E2E_PORT=5187`, `LOANSIGHT_API_PORT=8017`로 별도 포트의 Native API와 Vite를 사용했다. 기존 8000번 Compose API는 다른 작업 폴더에서 실행 중이므로 변경하지 않았다. desktop/tablet 스크린샷은 Playwright `test-results/`에 생성했다.

초기 샌드박스 실행에서는 pytest 임시 디렉터리 접근과 Vite 프로세스 생성이 거부되었다. 권한이 허용된 실행으로 위 검증을 완료했다. PostgreSQL 통합 테스트·MQ 파이프라인·기존 Compose 이미지 재배포는 이번 검증에 포함하지 않았다. 회사개황·업종 매핑·공시 수집·실제 분석은 구현 범위 밖이다.
