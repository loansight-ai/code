## 구현한 범위

승인된 구조화 사실을 위험규칙 입력으로 연결했다. 원문/수치 재검증·저장 당시 해시·
보고서 기간·미해결 충돌을 확인하며, 검수 철회·수정·원문 변경 시 다음 조회에서 제외한다.
다른 Workspace의 근거는 읽을 수 없다. 반려·대체된 사실도 사용하지 않는다.

정확한 필드 조건과 단일 금액 비교를 지원하는 버전별 규칙 실행기를 추가했다. 금액의
통화·한도/잔액 등 역할을 구분하고 Decimal로 비교한다. 명시적 부정과 실제 사유 발생을
구분하며, 실제 사건 규칙에는 상태 조건을 요구한다. 규칙 ID·버전·기준 출처와 사실 버전,
현재 근거 해시를 입력 revision에 반영한다. API 호출자가 규칙을 주입할 수 없다.

주석·위험징후와 예측 화면의 '현재 위험징후 규칙' 패널에서 범주별 준비 상태와 보류 사유,
규칙/입력 버전·검수 근거를 제공한다. 검수 결과 저장 뒤 관련 조회를 갱신한다. 정의되지 않은
규칙을 경고 0건 또는 정상으로 표시하지 않는다. 예측 모델 입력은 계속 보류다.

감사 후보 가져오기는 원천의 명시적 period가 보고서와 일치할 때 그 값과 직접 인용을
보존하도록 보완했다. 기간이 없거나 다르면 보고서 기간을 추정해 채우지 않는다. 변경은
structured-facts-v2이며 이전 후보나 승인 내용을 덮어쓰지 않는다.

## 실제 Codex 호출과 규칙 기준

시범 보고서 4건의 전용 검증 Workspace와 실행/결과 수집 절차를 준비했다. 설치된 Codex
CLI의 무인증 핸드셰이크와 인증 없을 때 turn을 시작하지 않는 동작을 검증했다. 공통
런타임 지시문은 특정 도구 3개로 고정하지 않고 제공된 근거 도구를 따르도록 수정했다.

실제 호출 설정은 처음부터 비활성 상태였고 워커 인증 파일도 없었다. 기존 호스트 인증을
전용 워커 볼륨에 복사하는 작업은 자동 승인 검토가 토큰 저장 위치 변경에 대한 명시적
승인을 요구하며 거절했다. 우회하지 않고 사용자에게 알렸으며, 사용자는 실제 호출 보류를
선택했다. 인증 파일 복사·서비스 실행 제한 활성화·실제 모델 호출은 수행하지 않았다.
무인 환경 인증 방식은 [OpenAI 공식 인증 문서](https://learn.chatgpt.com/docs/auth#login-on-headless-devices)를
확인했으며 토큰·키·쿠키를 프롬프트나 Git에 넣지 않는다.

사용자는 확정된 위험규칙 문서가 없다고 확인했다. 저장소의 N-U12/17과 23개 RISK 원자료·
단계 기준도 미정이므로 운영 registry는 비워 두었다. 합성 테스트 규칙은 실행기 검증에만
사용하며 실제 판정 기준으로 등록하지 않았다. 실제 위험 등급 판정 완료로 간주하지 않는다.

## 자동 검사

백엔드 전체 275 passed·5 skipped·16 subtests passed와 프론트 전체 23파일·141 passed를
확인했다. 백엔드 전체 검사에는 원천 기간 복사의 추가 2개 검사도 포함한다. 선택적 외부
연결 검사는 skip 수에서 구분하며 실행하지 않은 검사를 통과로 기록하지 않는다.

검사 내용은 승인/철회·기간/원문 변경·충돌·Workspace 차단, 정확한 필드 조건·금액 통화와
역할·Decimal 경계, 명시적 부정·사유 발생 구분, 미확정 규칙 미등록, 규칙/입력 버전 재현성,
기존 사실 수정 이력·Worker·검색 회귀와 설치된 CLI 프로토콜을 포함한다. 실제 모델 품질을
측정한 결과는 아니다.

공유 fixture와 합성 정의는 수집되는 테스트 모듈에서 분리했다. DB 검사는 loansight_test의
격리 스키마에서 수행했다. 초기 전체 검사에는 프론트 fixture 마운트 누락과 개발 환경의
API 설정 상속 문제가 있어 실행 환경을 바로잡았다. 컨테이너 재검사는 프론트 fixture를
읽기 전용으로 제공하고 서비스 환경변수·API 키의 대소문자 별칭을 제거한 뒤 수행한다.
중단된 환경 확인 실행은 테스트용 컨테이너만 종료했으며 서비스 컨테이너를 대상으로 하지 않았다.

TypeScript·Vite 빌드·ESLint와 변경 Python Ruff 검사를 수행했다. Vite의 기존 큰 청크
경고는 유지된다. 실제 브라우저 시각 검수는 하지 않았으며 화면 동작은 React DOM으로 검사했다.

## 보존과 남은 범위

기존 재무 분석 16건의 결과 MD5가 모두 보존됐다. 확인 시점에는 추가 분석 1건을 포함해
17건이 있었으며 이번 검증이 기존 결과를 덮어쓰지 않았음을 기존 ID별로 비교했다.
note_structure 18행, source_segment 15,282행, evidence_report 4행, evidence_segment
1,300행이 유지됐다. CSV 재작성·원천 확대·재무 누락값 자동 보완은 수행하지 않았다.

확정된 조건·임계값·적용 업종/기간과 기준 출처를 제공받아 검토한 뒤 운영 규칙을 등록해야
실제 등급 판정이 가능하다. 현재 실행기는 단일 사실에 한정하며 복수 사실·시계열·업종별
복합 규칙, 과거 판정 스냅샷 저장과 분석 revision 통합, 모델 특징/공개 시점 계약은 후속이다.
로컬에 적용했고 커밋·원격 푸시·PR 생성·외부 배포는 수행하지 않았다.
