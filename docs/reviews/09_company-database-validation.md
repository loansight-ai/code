# 기업 원장 PostgreSQL 적재 검증

> 2026-10-28 · PostgreSQL 17 · Python 3.12 · SQLAlchemy 2

## 변경

기존 기업 검색은 ZIP 원장과 CSV/스냅샷을 메모리에서 검색했다. 현재 검색 API는 PostgreSQL에 최초 적재한 기업을 조회한다. 적재·재시작·갱신·검색 계약은 [백엔드 기업 검색 안내](../../backend/README.md#기업-검색)에서 관리한다. 이전 수집 검증은 [주간 원장·KSIC11 검증](08_company-weekly-ksic11-validation.md)을 참고한다.

| 원장 파일 제거 및 `load()` 실패 주입 후 새 저장소 인스턴스로 검색 | 기존 DB만 사용 | 성공, 적재 시각 유지 |
| 업종·검색어·특수문자·영문 종목코드와 페이지 경계 | 전체 건수·정확 일치 우선·페이지 결과 일치 | 통과 |

실제 조회 시 총 건수는 전체 119,798, 제조 31,035, 건설 8,833, 도소매 11,839, 부동산 임대 4,391이었다. 원장·기업정보 갱신에 따라 달라질 수 있다. 최초 적재 체크포인트 시각은 한국 시각 2026-10-28 20:17:03이었다.

전체 검사에서 건너뛴 항목은 RabbitMQ 실연동 2개, Docker Compose 실행 환경 검사 2개, Windows 전용 파일 검사 1개다. 테스트 컨테이너에서 해당 환경을 제공하지 않았으며 통과로 기록하지 않는다. 실제 로컬 DB에는 마이그레이션 upgrade만 적용했다. 기존 DB·MQ·Worker·Relay와 데이터 볼륨은 유지했다.
