# 덤프 선택 적재·통합 근거 검증

검증일: 2026-11-01 (Asia/Seoul). 실행·API 계약은
[선택 근거 안내](../../backend/data/evidence/README.md), 후속 범위는
[통합 계획](../design/07_dump-evidence-integration.md)에서 관리한다.

## 구현한 범위

덤프의 필요한 네 테이블을 SQL 실행 없이 스트리밍으로 읽어 보고서별로 선택 추출했다.
별도 원천 DB에 원래 행과 체크포인트를 보존하고, 서비스 DB에는 검색용 구간을 게시한다.
기존 HTML 구조화 결과와는 사용자 소유권·기업·접수번호·기간·회계 범위를 확인한 뒤
불변 근거 묶음으로 연결한다. 기존 원문·구조화 작업을 덮어쓰지 않는다.

주석·위험징후와 위험 사건 예측 화면에 통합 목차·6항목 검색·출처별 검색·본문/표 문맥·
기존 HTML 원문 이동·Codex 비동기 보완 탐색을 연결했다. 구조화 ID가 없는 보고서와
재무가 없는 기업도 적재된 보고서에서 진입한다. 예측 화면의 사건 이력은 묶음 생성 당시
수집 적재 버전에 고정하며, 주석 근거는 계속 검수 전·모델 입력 보류다.

## 선택 적재 결과

원본 loansight_ofs_20261031.dump는 3,044,186,621바이트다. 전체 DB 복원과 모든 뷰
재계산을 하지 않았다. 원천 선택은
[명시적 목록](../../backend/data/evidence/pilot_selection.json)을 사용했다.

| 원천 | 스캔 행 | 선택 행 | 선택 JSONL 바이트 |
|---|---:|---:|---:|
| report | 26,248 | 4 | 1,818 |
| note_section | 1,270,922 | 108 | 1,386,489 |
| doc_section | 868,456 | 180 | 1,455,525 |
| audit_opinion | 43,811 | 8 | 11,529 |
| 합계 | — | 300 | 2,855,361 |

doc_section 중 64행은 원래 body_skipped다. 감사 원천은 CFS 4행·OFS 4행을 보존하며
OFS 묶음의 조회에서는 CFS를 제외한다. 선택 JSONL과 manifest의 해시·행 수·선택 키를
적재 전에 검증했다. 추출기 최적화는 선택되지 않은 행의 대형 본문을 역이스케이프하기
전에 식별자로 거르도록 했다. 같은 네 보고서를 다시 추출해 네 파일의 해시·행 수·내용
바이트와 manifest signature가 처음 결과와 모두 일치하는 것을 확인했다.

| 로컬 저장 | 결과 |

접속정보는 Git에서 제외되는 로컬 설정 파일로 전달했고 로그·문서·이미지에 넣지 않았다.
서비스 API는 원천 DB에 직접 연결하지 않는다.

## 실제 API 확인

새 검증 세션으로 각 보고서의 목록·근거 묶음 생성/재사용·6항목 검색·추가 키워드 검색·
본문/표 문맥·인용 구간 이동을 실행했다. scope는 OFS, 사건/조회 범위 적재 ID는
06a1e586-21e0-4b66-8dd4-dabb6db72bf6으로 고정되는 것을 확인했다.

| 기업 | 접수번호 | OFS/공통으로 조회되는 구간 | 복합 검색 후보 수 |
|---|---|---:|---:|
| 뉴트리 | 20260320001416 | 주석 181·사업보고서 137·감사 1 | 61 |
| 현대건설 | 20260318001395 | 주석 300·사업보고서 223·감사 1 | 136 |
| 삼성전자 | 20260310002820 | 주석 227·사업보고서 224·감사 1 | 123 |
| 알앤엘재생의학연구소 | 20170331004204 | 감사 1. 주석·사업보고서 미확보 | 1 |

복합 검색은 이자·차입·담보·계속기업·감사를 ANY로 검색했다. 후보 수는 정확한 사실 수나
위험 발생 건수가 아니다. 본문과 표는 각각 검색 구간이므로 같은 사실이 중복될 수 있다.
기존 자료의 정확도나 모델 성능을 측정한 결과가 아니다.

다른 새 사용자 세션에서 첫 사용자 묶음 조회가 404로 차단됨을 확인했다. 검증 세션의 코드와
쿠키는 출력하지 않았으며 성공한 검증의 세션은 종료했다. 실제 유료 Codex 탐색은 실행하지
않았고 테스트 런타임으로 도구 호출·인용·작업 완료를 검사했다.

## 기존 데이터 보존과 한계

기존 재무 분석 16건의 result::text MD5가 적용 전후 모두 일치했다. 기존 note_structure
18행, source_segment 15,282행, 수집 CSV 적재 2버전도 유지됐다. 이번 검증에서 재무 분석을
새로 계산하거나 기존 사용자 원문을 변경하지 않았다.

브라우저 제어 도구의 호스트가 사용 불가여서 실제 브라우저 시각 검수는 수행하지 못했다.
화면 동작은 React DOM 검사, 서비스 연결은 실제 HTTP로 확인했다. 원본 ZIP/XML 파일
복원·전 기업 적재·전체 검색 정확도 평가·실제 모델 추론은 수행하지 않았다.

이 구현은 자료 결합과 근거 조회다. 중복 사실의 자동 통합·충돌 금액 선택, 담당자 사실
검수 저장, 위험규칙 자동 판정, 예측 입력의 시점 적합성 승인·모델 추론, 재무 누락값 자동
보완은 후속이다. 원천에 없는 XPath·병합·공개 시각을 생성하지 않으며 모든 근거는 PENDING,
모델 입력은 WITHHELD_UNVERIFIED로 남긴다.

작업 브랜치는 data/ofs-export-20261101이다. 앞선 OFS 전환 변경을 보존하며 이번 코드를
추가했다. Issue/PR 생성·커밋·원격 푸시·외부 배포는 수행하지 않았다. 실제 적용은 로컬
Compose 환경으로 한정한다.
