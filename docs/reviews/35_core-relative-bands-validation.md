# 핵심 5개 비율의 화면 상대 구간 적용 검증

검증일: 2026-11-01 (Asia/Seoul).

사용자가 제공한 [화면 비교 CSV](../../backend/data/2016-2025_화면비교기준.csv)를
[적용 규칙](../../backend/data/화면_상대구간_적용규칙.md)에 맞춰 연결했다.
실행·저장 계약과 남은 산식 제한은 [핵심 카드 안내](../../backend/README.md#핵심-5개-비율-카드-평가)를 따른다.
기존 문서 점검 변경과 dump는 보존했으며 이번 구현에 포함해 수정하지 않았다.

합성 브라우저 fixture는 실제 새 CSV와 기존 재무 fixture를 백엔드 함수로 계산해 생성했다.
실제 로컬 확인은 새 검증 세션의 수집 CSV 분석이며 OpenDART 재수집·모델 호출·사실 승인을
하지 않았다. 캡처를 열어 카드·상세의 PC/모바일 배치를 확인했다. 상세 표만 가로로 탐색한다.
모바일의 페이지 전체 공통 헤더에서 관찰한 기존 소폭 가로 넘침은 이 카드 변경 범위 밖이며,
모바일 전체 페이지 무넘침을 통과한 것으로 기록하지 않는다.

이전 표시 계약이 고정된 분석도 조회 시 새 계약으로 보완하고 저장된 원문·계정·비율·기존
기준 JSON을 덮어쓰지 않는 것을 API 통합 검사로 확인했다. 새 계약 기준은 고정하며 CSV
해시는 새 분석 재사용 키에 포함된다. 개발 API·Worker·Relay를 갱신했고 개발 DB 볼륨은
유지했다. 검증 인프라는 별도 테스트 DB·RabbitMQ를 사용했다.

## 비교를 보류하는 항목

부동산은 행의 실제 비교산업이 부동산임대업인 기준만 해당 비교에 사용한다. 부동산업 전체
기준이나 부분결측 경계를 다른 출처로 채우지 않는다. 부동산임대업 총자산영업이익률은
원자료의 손익기간 미확인 사유를 표시한다. 다른 업종의 총자산영업이익률도 기존 회사값의
기말 자산 산식과 비교자료의 평균 자산 산식 일치를 확인할 때까지 참고값으로 제공한다.
상대 구간을 위험·안전 등급이나 기업별 구간 이동 확률로 해석하지 않는다.
