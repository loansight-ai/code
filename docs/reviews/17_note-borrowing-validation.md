# 주석 차입금 소계 검증

> 2026-10-29 · 오뚜기 실제 공시 기준

오뚜기 2025.12 사업보고서(접수번호 `20260318000621`)의 자본관리 주석을 기존 수집기로 확보하여 별도·연결 범위를 각각 검증했다. 데이터 계약과 추출 조건은 [백엔드 재무 계약](../../backend/README.md#financial-api)에서 관리한다.

| 회계 범위 | 주석 소계 · 리스 제외 (원) | 리스 포함 소계 (원) |
|---|---:|---:|
| 별도 OFS | 419,636,531,000 | 427,678,910,010 |
| 연결 CFS | 789,730,415,000 | 861,100,020,361 |

두 범위 모두 실제 API→Outbox→RabbitMQ→Worker→PostgreSQL→화면 경로에서 분석 완료를 확인했다. 주석의 표시 단위로 검산하며 정형 API 원 단위 금액의 반올림 차이를 검산에 섞지 않았다. 기존 전체 차입금은 미확보 구성 계정 때문에 계속 보류되며 주석 소계와 별도로 표시된다.

| 검증 | 결과 |
|---|---|
| 재무 단위 테스트 | 15개 통과. 실제 별도 주석, 검산 불일치·외화 거부, 리스 누락 보류 포함 |
| 재무 DB 통합 테스트 | 4개 통과. 주석 소계 금액·출처·제한 범위의 저장/응답 포함 |
| 재무 요약 화면 테스트 | 5개 통과. 소계·전체 차입금 구분, 검산 근거, 산식 표시 포함 |
| 정적 검사·빌드 | Ruff, TypeScript·ESLint·Vite 통과. 기존 Vite 큰 청크 경고 유지 |
| 실제 브라우저 | OFS/CFS 소계·검산 근거·리스 옵션 전환 확인. 태블릿 가로 넘침 없음, 페이지 오류 0 |

별도 실제 주석 발췌는 `backend/tests/fixtures/ottogi-capital-notes.html`에 원본 해시와 함께 보존했다. 로컬 화면 캡처는 `.run/financial-validation/note-borrowing-OFS.png`, `note-borrowing-CFS.png`이며 Git에는 포함하지 않는다. 마이그레이션 변경은 없다. 이번 검증은 지원한 표 형식과 오뚜기 표본에 한정하며 모든 기업의 주석 형식을 검증한 것은 아니다.
