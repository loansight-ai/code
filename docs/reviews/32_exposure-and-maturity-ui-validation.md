# 보증 구성·1년 내 만기·소송 화면 검증

검증일: 2026-11-01 (Asia/Seoul).

사용자 참고 화면의 3번 구성 표와 4번 만기 요약을 기존 추출 현황 아래에 배치했다.
4-B 소송 현황도 오른쪽 아래 카드로 연결했다. 집계·단위·출처·검수 범위는
[담당 계약](../../backend/data/evidence/README.md#exposure-summary)에서 관리한다.

## 검증

- 백엔드 관련 40 passed: 금액 역할·제공/수취 분리, 상세/총계/중복 셀 구분, 사업장 수
  오합산 방지, 미확보/명시적 0, 소송 중복/상위 사건, Decimal 정밀도, 1년 경계/윤년/
  기준일 전 만기/자본 0 이하와 기존 검수·위험규칙 흐름을 확인했다.
- 분리된 PostgreSQL 테스트 DB에서 사용자 권한, 승인 전 집계 보류, 실제 원문 열람·승인 후
  집계 포함, 원문 변경 후 집계 제외를 검사했다. 개발 DB에 테스트 사실을 넣지 않았다.
- 관련 React 4파일·14 passed: 분자·수취 제외·미공시 금액, 미확보의 0 오표시 방지,
  잘못된 묶음 응답 차단과 기존 검색/사실 검수 흐름을 확인했다.
- Playwright Chrome PC·태블릿 2 passed. 각 실행에서 모바일 390px도 검사했다.
  구성/만기/소송 카드, 원문 패널, 만기 사다리 이동과 가로 넘침 없음, 기존 검수 도구를
  확인했다. 숫자가 채워진 화면은 테스트 전용 합성 응답이며 운영 데이터가 아니다.
- 실제 현대건설/20260318001395/OFS를 새 검증 세션으로 열어 집계 API 200, 올바른
  기간·범위와 세 카드 표시를 확인했다. 1640px·820px에서 가로 넘침=false·pageerror=0.
  집계용 사실 미확보는 미확보로 표시했고 모델 호출·사실 승인은 하지 않았다.
- 실제/합성 캡처를 열어 배치를 확인했다. 캡처는 Git 제외 경로에 저장하고 실제 세션의
  사용자 코드 영역은 가렸다. TypeScript/Vite·ESLint·관련 Ruff 검사 통과.

기존 사실·원문·인증 자료를 수정하지 않았으며 로컬 API/Worker/Relay만 새 코드로
갱신했다. 기존 문서 점검 변경은 보존했다. 운영 위험규칙 등록·모델 추론은 여전히 별도다.
