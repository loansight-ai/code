# 기업 검색 이동 시 활성 재무 분석 유지

2026-10-30

기업 검색 경로에 재무 분석 ID가 없어 공통 셸의 메뉴가 `/workspace`로 돌아가고 상단 분석 기준이 사라졌다. 이제 결과가 있는 재무 분석을 열면 현재 작업공간의 활성 분석으로 기억한다. 검색 화면에서도 같은 결과를 조회해 상단 기준과 요약·현금흐름 메뉴를 유지한다. 검색 중 기업이나 보고서를 고르는 동작은 기존 활성 분석을 교체하지 않는다. 새 결과를 열면 해당 분석으로 갱신하고 결과 없는 진행 중 작업은 완료된 선택을 덮어쓰지 않는다.

같은 브라우저 탭의 `sessionStorage`에 작업공간별 분석 UUID만 저장한다. 결과·세션 코드·토큰은 저장하지 않는다. 저장소가 차단되면 메모리로 현재 방문 중 선택을 유지한다. 사용자 작업공간이 달라지거나 세션 확인 중이면 이전 분석을 사용하지 않는다. 결과는 기존 사용자별 서버 조회를 통해 확인하고 403·404로 접근할 수 없는 기억은 해제한다. 예시 화면과 주석 화면의 기존 경로는 변경하지 않는다. 백엔드 변경은 없다.

단위 검사는 작업공간 격리·세션 없는 상태·저장 UUID 검증·저장소 차단 시 유지를 확인한다. 브라우저 검사는 재무 결과 → 기업 검색 → 새로고침 → 결과 복귀와 다른 작업공간의 초기 메뉴를 확인한다. 데스크톱·태블릿에서 같은 흐름을 확인한다.

검증 결과: TypeScript·ESLint·프로덕션 빌드 통과, 전체 프런트 테스트 112개와 관련 브라우저 검사 8개 통과. 빌드는 기존 대형 번들 경고를 출력한다.
