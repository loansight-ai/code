# 핵심 5개 비율 업종 사분위 비교 검증

검증일: 2026-11-01 (한국 시각)

구현 계약과 데이터 한계는 [핵심 카드 평가](../../backend/README.md#핵심-5개-비율-카드-평가)에서 관리한다. 팀 제공 대화와 카드 이미지를 기준으로 기존 평균 비교선·고정 가설 판정을 중앙값·사분위 상대 위치 표시로 변경했다. 별도 위험징후 패널과 5개 영역 레이더의 점수·정확한 백분위는 변경하지 않았다.

백엔드 명령은 개발 볼륨과 분리된 `deploy/compose.test.yaml`의 PostgreSQL·RabbitMQ를 사용했다. 저장소를 읽기 전용으로 마운트하고 `pytest -p no:cacheprovider`를 실행했다. 첫 실행의 BOK 6건은 프론트엔드 공용 fixture를 마운트하지 않아 실패했으며 저장소 전체 구조로 수정 후 위 최종 결과를 확인했다.

브라우저 테스트는 실제 CSV로 백엔드가 생성한 API fixture를 사용한다. 실제 개발 DB 네 건 확인은 읽기 전용 평가 함수 검사이며, 사용자 세션의 실제 HTTP 화면을 자동 조작한 결과로 기록하지 않는다. 임시 Vite 서버 종료가 지연되어 기존 로컬 개발 서버를 재사용한 최종 Playwright 명령의 정상 종료를 확인했다.

후속 표시 수정에서는 전기값을 회색 세로선으로만 남기고 중복 회색 막대를 제거했다. 당기 채움은 음수 기준값이 있는 축에서도 왼쪽 끝부터 당기 위치까지 이어지도록 변경했으며 수치·분위수·비교선 위치는 유지했다. 관련 Vitest 13개와 데스크톱 Playwright 1개를 재실행해 통과했고 캡처로 확인했다.

## 남아 있는 제한

CSV의 셀별 원천·표본 수·보충 여부와 산식 증빙은 추가 확보가 필요하다. 비교자료 자체의 외부 원문 전수 대조는 이번 작업에서 수행하지 않았다. 부동산 임대업 제외/리츠 전환, 평균 총자산 기준으로 자사 산식 변경, 부족한 사분위값 보충, 2015년 자료 생성은 수행하지 않았다. 기존 결과와 수집 CSV에는 자본금이 없을 수 있어 부분자본잠식은 확정 자본금이 확보된 경우에만 표시한다.

GitHub 이슈 생성은 자동 승인 검토에서 구현 요청에 외부 이슈 생성 승인이 없다는 이유로 차단되었다. 원격 이슈·PR은 생성하지 않았으며 로컬 작업 브랜치에서 기존 사용자 변경을 보존했다.
