# 실적 변동·현금흐름 시각화 검증

2026-10-30 · 실제 결과 경로 `/financials/:financialId/cashflow`

## 적용 내용

- 기존 ECharts 공통 컴포넌트로 영업이익 변동 분해와 기간별 영업이익·영업활동현금흐름을 나란히 표시한다. 좁은 화면에서는 세로로 배치한다.
- 합계는 진한 회갈색, 증가는 연한 회갈색, 감소는 연분홍, 음수 현금흐름은 빨간색이다. 영업이익 분해의 증가·감소는 원인 추정이 아닌 회계상 증감을 뜻한다.
- 실제 결과 API의 `profit_bridge`, 원천 계정과 비교기간을 사용한다. 백엔드·저장 스냅샷·계산 정책 변경은 없다.
- 분해 금액은 원 단위 소수 여섯 자리까지 정수로 변환해 전기 영업이익과 증감 합계가 당기 영업이익에 일치하는지 검산한다. 누락·불일치 시 차트를 보류한다. 차트는 0을 넘나드는 증감도 표시한다.
- 현금흐름 차트는 실제 비교기간 수와 회계 범위를 표시하고 결측을 0으로 채우지 않는다. 이전 현금흐름이 확인된 비음수일 때만 음수 전환으로 설명한다. 표시기간 모두의 이익이 양수일 때만 모두 흑자로 설명한다.
- CFS/OFS 상대 범위 데이터는 현재 결과에 없으므로 비교 스위치는 비활성 상태와 사유를 표시한다.
- 금액·자료 상태와 검산 표는 펼쳐서 확인한다. 기존 원천 계정과 근거 열람 기능을 유지한다.
- `/examples/financial-cashflow`는 같은 컴포넌트에 명시적 가상 건설 기업 데이터를 사용한다. 실제 결과의 누락값을 예시 금액으로 대체하지 않는다.

## 검증

- 단위 검사: 영업이익 분해의 0 교차, 소수 금액 정합성, 실제 0, 누락·불일치 보류, 현금흐름 설명의 전환 조건.
- 브라우저 검사: 실제 API 응답 기반 재무 결과에서 두 차트 표시, 예시 메뉴 이동·금액 표·음수 현금흐름, 데스크톱·태블릿·390px 화면의 가로 넘침과 실행 오류 확인.
- 검증 결과: TypeScript·ESLint·프로덕션 빌드 통과, 프런트엔드 전체 102개 테스트 통과, 관련 브라우저 검사 8개 통과. 새 컴포넌트·차트·검사 파일의 Prettier 검사와 `git diff --check`도 통과했다. 빌드는 기존 대형 번들 경고를 출력한다.

기존 핵심 요약의 적용 내역은 [시각화 요약 검증](20_visual-financial-summary-validation.md), API 계약과 기존 제한은 [재무 API](../../backend/README.md#financial-api)를 따른다.
