# 구조화 사실 추출·검수 검증

검증일: 2026-11-01 (Asia/Seoul). 구현·API·상태 전이의 상세 계약은
[사실 검수 안내](../../backend/data/evidence/README.md#structured-facts)에서 관리한다.
이 기록은 앞선 [통합 근거 구현](27_dump-evidence-integration-validation.md)의 후속이다.

## 구현한 범위

고정된 보고서 근거 묶음에서 기존 HTML과 선택 적재 덤프를 함께 사용하는 구조화 사실을
추가했다. 감사의견·계속기업·차입 만기·약정·신용등급·담보·소송·제재·보증·후속 사건을
대상으로 필드별 인용과 원문 금액 셀을 저장한다. 직접 작성, 명시적 덤프 감사기록 재사용,
설정된 Codex 런타임의 제한된 비동기 추출을 지원한다.

사람의 원문 열람·승인·반려·재검수와 사유를 저장한다. 수정은 이전 내용을 보존하고 새
PENDING revision을 생성한다. 검수 이력과 수정본 간 이동을 두 화면에 연결했다. 다른
출처의 동일 필드·충돌 가능 후보를 표시하며 자동 병합이나 출처 우선순위를 만들지 않는다.

금액 셀·단위·통화·기간 머리글·인용을 검사하고 모호한 필드는 승인을 차단한다. 화면에서
표시되지 않는 열/긴 금액 셀도 승인할 수 없다. 사람의 의미 판단과 기계 검사를 구분한다.
승인된 사실도 model_eligible=false로 남는다.

## 로컬 서비스 확인

새 migration 06a9c2d40210을 서비스 DB에 적용하고 API·Worker·Relay를 새 이미지로
갱신해 healthy 상태를 확인했다. evidence_fact / fact_opening / fact_review /
fact_extraction을 추가했으며 원천 DB의 선택 적재량은 늘리지 않았다.

새 검증 Workspace에서 실제 HTTP로 다음 보고서를 확인했다.

| 기업 | 접수번호 | 감사의견 후보 | 상태 |
|---|---|---:|---|
| 뉴트리 | 20260320001416 | 1 | PENDING · 인용 일치 |
| 현대건설 | 20260318001395 | 1 | PENDING · 인용 일치 |
| 삼성전자 | 20260310002820 | 1 | PENDING · 인용 일치 |
| 알앤엘재생의학연구소 | 20170331004204 | 1 | PENDING · 인용 일치 |

같은 감사기록 가져오기는 같은 후보를 재사용했다. 원문 열람 전 승인 요청은 409로
차단됐고, 원문 열람 후에도 검수 이력이 자동 생성되거나 승인이 이뤄지지 않음을 확인했다.
CFS 감사 자료는 OFS 묶음에서 제외됐다. 원문의 Y/N만으로 계속기업 위험 부재를 생성하지 않았다.

실제 금융 사실의 승인·반려 판단은 남기지 않았다. 검증 세션은 종료했고 코드·쿠키·
인증정보는 출력하지 않았다. 실제 유료 Codex 추출은 호출하지 않았으며 외부 런타임과의
도구/출력 계약은 테스트 런타임으로 검사했다.

  수정본의 승인 초기화·이전 이력 보존, Workspace 분리, 덤프/HTML 사실 결합,
  금액·대시·단위·통화·방향·명시적 부정문 검사, 미조회 인용 거부, Worker 저장,
  중단 시 모델 자동 재호출 금지·실행 임대 검사, 기존 검색/에이전트/Worker 회귀,
  Alembic upgrade·모델 일치·downgrade를 포함한다.
- 마지막 화면 표시 한계 보완 후 사실 검수·기간 검사 23 passed를 추가 확인했다.
  표시되지 않는 금액 열만으로 승인이 차단되는 강화된 검사도 1 passed로 별도 확인했다.
- 프론트 전체 22파일·138 passed. 추가 3개는 원문 열람·사유 없는 승인 방지,

- 마지막 수정본 이동·표시 변경 후 관련 2파일·7 passed를 별도로 확인했다.

## 데이터 보존과 남은 범위

기존 financial_run 16건의 result::text MD5가 적용 전후 일치했다. note_structure 18행,
source_segment 15,282행, evidence_report 4행, evidence_segment 1,300행과 수집 CSV
적재 2버전이 유지됐다. 원천 전체 복원·전 기업 적재·기존 CSV 재작성은 수행하지 않았다.

예측 모델 특징·공개 시각/시점 적합성·위험규칙 연결은 후속이다. 승인된 사실을 자동으로
예측 입력이나 재무 누락값 보완으로 사용하지 않는다. note_fill / fs4_note_applied의
추가 적재도 하지 않았다. 임계값·예측 대상·승인 권한의 조직 정책을 임의로 정하지 않았다.

로컬 Compose에 적용했으며 커밋·원격 푸시·PR 생성·외부 배포는 수행하지 않았다.
