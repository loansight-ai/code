실제 조회 시각은 한국 시각 2026-10-28 21:12:58이며, 1999-01-01 이후 접수 공시에서 확인한 결산기간이다. 제출연도와 사업연도를 혼동하지 않으며 이 범위 밖 자료가 없다고 단정하지 않는다. 사업보고서 존재가 연결·별도 재무정보 모두의 제공을 의미하지 않으며 실제 분석은 실행하지 않았다. 화면 캡처는 Git 제외 경로 `frontend/test-results/`에 저장했다.
