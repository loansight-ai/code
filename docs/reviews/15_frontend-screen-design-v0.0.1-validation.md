# 화면설계서 v0.0.1 프론트 반영 검증

검증일: 2026-10-29. 브랜치 `feat/frontend-screen-design-v001`. 기준은 [화면설계서 PDF](<../02_LoanSight AI_화면설계서_v0.0.1.pdf>) 11쪽이며, SHA-256은 `8ad2880327e7697212a16241009c2e90a27e966e093db8496098fabd7225e640`이다. 기존 문서에 기록한 v0.0.2 파일과 같은 내용이며 현재 파일명에 맞춰 참조 링크를 갱신했다. 사용자가 교체한 PDF는 내용 변경 없이 파일명 변경으로 반영한다.

## 반영 범위

공통 셸·기업 검색 표·분석 컨텍스트를 먼저 구성하고, 실제 주석·Codex 결과의 탭·인용 드로어를 연결했다. 다음으로 영업이익 우선 요약·핵심 비율·3개년 현금 비교·업종 지표/만기 자료 상태·예측 보류 구성을 반영하고 실제 근거 후보를 담당자 검토에 연결했다. 상세 실행 계약은 [프론트엔드 안내](../../frontend/README.md#screen-design)에서 관리한다.

## 검증 결과

| 검증 | 기대 | 실제 |
|---|---|---|
| Vitest 전체 | 기존 검색·보고서·검토 동작과 실제 보고서 메뉴 연결 유지 | 12개 파일, 72개 통과 |

| 실제 주석 워크스페이스 컴포넌트 | 보고서·OFS 유지, 실데이터에 예시 숫자 없음, 원문 표시 통지 전 체크 차단, Workspace별 로컬 기록 분리 | `live-workspace.test.tsx` 2개 통과; 전체 72개에 포함 |
| PostgreSQL 기업 검색 | 시장 필터를 count·pagination 전에 적용, 잘못된 시장 422, 기존 기업 검색 회귀 | `test_company_database.py` 8개 통과 |
| TypeScript·ESLint·Vite build | 타입·lint·배포 빌드 성공 | 통과. 기존 대용량 JS 청크 경고 표시 |
| Ruff 변경 Python 파일·Git diff check | 관련 코드 정적 검사·공백 오류 없음 | 통과 |
| 로컬 화면 확인 | 검색·재무 요약·위험징후·검토의 정보 배치와 반응형 확인 | Chrome 캡처 육안 검토, PC·태블릿 가로 넘침 없음 |
| 로컬 API 적용 | 시장 필터와 원문 저장일 제공 | 이미지 빌드·API 재생성 및 healthy 확인. Worker·DB·Codex 인증 볼륨 유지 |

새 주석 워크스페이스 E2E는 인증·보고서·검색·Codex 응답을 고정 fixture로 제공하고 실제 iframe 렌더링과 브라우저 저장을 검증했다. 새 유료 모델 호출이나 실제 공시 재수집을 실행한 검사는 아니다. 예시 분석 E2E는 기존 가상 데이터 흐름을 검증했다. 캡처·trace는 Git 제외 `frontend/test-results/`와 `.run/screen-design-review/`에 보관하며 사용자 코드는 캡처에서 가렸다.

초기 검증에서 화면명 변경·중복 텍스트 선택자·예시 초기화 후 실데이터 화면 전환·보고서 선택 초기화 문제가 발견되어 수정했다. 컴포넌트 테스트는 원문 렌더 통지 콜백을 대체하고, 실제 iframe 열람 게이트는 Chrome E2E로 검증했다. 시장 필터 테스트는 PostgreSQL만 필요하며 테스트용 RabbitMQ 시작 실패 후 DB만 기동해 실행했다. 실패한 시도는 통과로 기록하지 않았다.

## 유지한 범위와 한계

재무 계산·위험규칙·외부 모델·제공/수취 금액·일정의 검증된 서버 결과가 없으면 자료 없음·미평가·예측 보류를 표시한다. 실제 업무 사실로 승격하거나 임의 확률·합계를 만들지 않는다. 검토 저장은 현재 브라우저 한정이며 서버의 담당자 승인·열람 이력 저장은 후속이다. 모든 원문 열람은 이해·의미 검증의 증명이 아니다.

뉴스 수집, 독립 검증 화면, 업종 수동 변경·직접 입력 저장, 실제 23개 RISK 후보 원자료 대조, 최신 기획의 전체 기능 구현은 포함하지 않는다. OFS 기본과 현행 검토 범위를 유지하며 PDF의 예시 숫자·17항목을 정책으로 확정하지 않았다.
