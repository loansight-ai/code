# Code — 금융·AI 최종 프로젝트

금융·AI 최종 프로젝트의 실행 코드와 실행 환경을 관리하는 비공개 저장소입니다.

- 최종 주제, 서비스명, 시작일, 팀원 및 역할: 미정
- 현재 상태: 저장소 초기 구성. 구현·분석·검증 결과는 아직 없습니다.
- [기획·설계·수행일지·발표 문서](https://github.com/fin-ai-lab-2026/docs)
- [조직 Overview](https://github.com/fin-ai-lab-2026)

## 디렉토리

```text
code/
├─ README.md
├─ CONTRIBUTING.md
├─ .gitignore
├─ .github/
│  ├─ ISSUE_TEMPLATE/
│  │  ├─ task.md
│  │  └─ bug.md
│  └─ pull_request_template.md
├─ source/
├─ tests/
├─ data/
│  └─ README.md
└─ output/
```

`source/`, `tests/`, `output/`은 현재 폴더 유지를 위한 `.gitkeep`만 있습니다.

## 실행 환경 및 실행 방법

언어, 라이브러리, 버전, 실행 명령 및 외부 서비스는 미정입니다.
실행 가능한 코드가 추가되면 의존성 파일과 처음부터 끝까지 실행하는 방법을 이 문서에 기록합니다.
현재는 실행할 프로그램이 없으며 실행 검증을 수행하지 않았습니다.

## 데이터

출처, 수집 방법, 컬럼, 전처리 및 이용 조건은 [data/README.md](data/README.md)에 기록합니다.
아직 데이터를 수집하지 않았습니다.

## 분석 및 결과

분석 내용과 결과는 미정입니다. 생성된 결과 파일은 `output/`에 저장하고, 설명과 검증 근거를 이 문서에 연결합니다.

## 협업

[협업 규칙](CONTRIBUTING.md)을 따릅니다.
개발 할 일과 오류는 이 저장소의 Issues에서 관리하고, 구현 변경은 PR로 검토합니다.
제출·발표 자료는 `docs`에서 관리하며 중복 편집하지 않습니다.
