# LoanSight AI — 실행 코드

기업 여신심사를 위한 핵심 재무정보 시각화·실적 변동·재무와 주석 결합 부도위험 분석 서비스 **LoanSight AI**의 실행 코드와 실행 환경을 관리하는 비공개 저장소입니다.

- 저장소 상태: `source/`, `tests/`, `output/`은 아직 `.gitkeep`만 있습니다. 기존 로컬 시연 코드와 구분하며, 이 저장소에서 실행·학습·검증 완료를 확인한 상태는 아닙니다.

## 서비스 흐름과 개발 범위

**기업 검색·업종 선택 → 자료 수집·기준 통일 → 재무·주석 분석 → 부도 확률·관련 근거 확인 → 담당자 체크·검토 기록 → 최종 판단**

핵심 개발 범위는 영업이익·현금흐름 시각화, 실적 변동 분석, AI 주석 추출·요약, 재무·주석 결합 12개월 부도 확률 예측, 확인 체크와 검토 기록 초안입니다. 뉴스는 보완 기능이며 초기 예측 모델 입력에서 제외합니다.

숫자·비율은 분석 코드로 계산하고, AI는 주석 구조화와 근거 있는 요약에 활용합니다. 예측 모델은 재무 단독 기준 모델과 비교 검증하며, 최종 여신 판단은 담당자가 수행합니다. 상세 기획은 [프로젝트 문서](https://github.com/fin-ai-lab-2026/docs/blob/main/README.md)에서 관리합니다.

## 실행 환경 및 실행 방법

기획상 기존 Python 웹 시연 코드를 기반으로 OpenDART, 재무 분석·예측 모델, 언어모델 API 연계를 확장할 계획입니다. 이 저장소에서 재현 가능한 실행 환경·버전·의존성·실행 명령은 코드 반영 후 확정합니다.
실행 가능한 코드가 추가되면 의존성 파일과 처음부터 끝까지 실행하는 방법을 이 문서에 기록합니다.
현재는 실행할 프로그램이 없으며 실행 검증을 수행하지 않았습니다.

## 데이터

출처, 수집 방법, 컬럼, 전처리 및 이용 조건은 [data/README.md](data/README.md)에 기록합니다.
기획상 OpenDART 재무제표·공시 원문·주석·부도발생 이력을 활용합니다. 이 저장소의 실제 데이터 수집·적재 완료는 아직 확인되지 않았습니다.

## 분석 및 결과

실적 변동 기여도, 영업이익·현금흐름 차이, 비교 가능한 업종 분포와 재무·주석 결합 부도 예측을 개발 범위에 포함합니다. 실제 분석·학습 결과와 성능 검증 수치는 아직 게시되지 않았습니다. 생성된 결과 파일은 `output/`에 저장하고, 설명과 검증 근거를 이 문서에 연결합니다.
