# LoanSight AI 재무 분석 과정

이 폴더는 과거 연구 과정을 순서대로 정리한 독립 자료입니다. 웹 서비스의 설정·실행 경로와 연결하지 않습니다. 기업별 데이터, DB 덤프, 공시 원문, 모델 파일은 포함하지 않습니다. 이 문서의 결과는 연구 당시 기록이며 현행 서비스에 반영되었거나 위험 판정으로 승인되었다는 뜻이 아닙니다.

## 1. 재무제표 및 주석 데이터 준비

2015년 이후 DART 별도재무제표(OFS)와 주석·공시 사건 후보를 수집하고, 계정 매핑·표준화·추출 상태와 출처를 점검했습니다. 주석에서 찾은 값, 해당 없음, 미검출, 추출 실패를 구분했습니다. 기업 식별자와 공시 접수번호는 문자로 보존해야 합니다. 사건 후보는 원문 검증 전이며 확정 연체 라벨이 아닙니다.

## 2. 업종별 비교 기준 마련

제조·도소매·건설·부동산임대 연구 자료에서 유동비율, 부채비율, 매출액영업이익률, 총자산영업이익률, 이자보상비율을 살폈습니다. 한국은행 ECOS 공표값과 OFS 수집 표본의 분위수를 구분했습니다. 공표값이 없는 곳에 표본값을 보충할 때 원천과 산식을 기록했고, 부동산업과 부동산임대업의 범위 차이를 남겼습니다. 이 연구의 네 업종은 현행 제품 범위나 구현 상태의 확정을 의미하지 않습니다.

## 3. 2016~2025 분포와 불확실성 분석

저장된 기업별 감사 표본을 이용해 연도·업종·지표별 분포, 사분위수와 부트스트랩 95% 신뢰구간을 계산했습니다. ECOS 공표 분위수를 기업별 원자료처럼 재추출하지 않았습니다. 기업값을 고정한 뒤 재추출·한 기업 제외·양끝값 제외 시 구간 배정이 얼마나 바뀌는지 살폈습니다. 신뢰구간은 개별 기업 위험 확률이 아니며 수집 표본이 업종 전체를 대표한다는 증거도 아닙니다.

분포·민감도와 상대 구간 표시를 계산한 원본 코드와 독립 검사는 [code](code/)에 있습니다. 입력 자료는 포함하지 않으므로 별도로 준비해야 하며, 기본 실행은 파일을 읽고 결과 파일을 쓸 수 있습니다.

## 4. 2025년 위험징후 지표와 사건 후보 탐색

2025년 업종별 지표의 표본 분포와 사분위 경계, 자료 부족 및 정성 항목을 검토했습니다. 공시 사건 후보를 재무정보 공개 시점 이후 추적하는 탐색을 수행하고, 별도 제공된 사건 자료의 원문 수치·지표 근거를 대조했습니다. 사건 원문 검증이 충분하지 않고 동일 기준의 실제 연체 정답이 부족해 확정 정상군이나 실제 연체 예측 성능으로 취급하지 않았습니다. 가설 임계값은 운영 규칙이 아닙니다.

## 5. 이상 탐지와 군집 비교

상환연체 정답 부족을 고려해, 업종 내 드문 재무 패턴과 비슷한 기업군을 살펴보는 비지도 연구를 수행했습니다. 업종별 선정 지표, 누락·대치, 무차입, 분석 보류를 구분했고 군집 번호는 위험 순위가 아닙니다. K-means·Isolation Forest를 기준으로 대안 모델을 비교했지만 전면 교체가 확정된 것은 아닙니다. 모델 학습 코드는 이 저장소의 운영 범위에 포함하지 않습니다.

## 6. 재학습과 연도별 확인 기록

2025년 품질 연결 수정·재학습 결과는 2025년 범위이며 다른 연도의 검증 완료를 뜻하지 않습니다. 이후 2016~2025년 선택 연도별 계산·학습·검증 결과를 정리했습니다. 연구 기록에서의 완료와 현행 서비스에 대한 배포·병합은 별개입니다.

## 코드 실행 및 검증 범위

- `run_yearly_eda.py`: 연도별 표본 분포·부트스트랩 CI. `numpy`, `matplotlib` 필요.
- `run_sensitivity.py`: 구간 배정 민감도. `run_yearly_eda.py`를 함께 사용.
- `reclassify_relative.py`: 산출된 CI·민감도를 이용해 상대 위치 안내 생성.
- `test_sensitivity.py`: 경계, 동점, 한 기업 제외 계산에 대한 가상 숫자 검사.

원본 스크립트의 기본 경로는 스크립트 옆의 입력 파일을 가리킵니다. 실제 입력은 이 저장소에 없으며 코드만으로 전체 재현은 되지 않습니다. 다른 작업공간에 자료를 별도로 준비하고 입력·출력 경로를 확인한 다음 실행해야 합니다. 데이터 업로드·다운로드나 서비스 연결은 이 변경에 포함되지 않습니다.
